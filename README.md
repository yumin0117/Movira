# Movira · 사진과 동영상의 움직임을 보다

[웹사이트 열기](https://yumin0117.github.io/Movira/) · [코드 저장소](https://github.com/yumin0117/Movira)

사진·동영상에서 여러 사람을 찾고, 각 사람의 관절·뼈대·뒤꿈치·발끝을 표시하는 웹 앱입니다. 사람 크기에 맞춰 화면을 나누어 찾고 중복을 줄입니다. 양쪽 어깨와 같은 쪽 골반도 이어 몸통 양옆을 표시합니다.

**몸과 양손·손가락을 함께 인식**합니다. 사람별 손목에 연결된 손 영역을 분석하고, 손마다 21개 표시점을 같은 영상 프레임에 그립니다. 손은 청록색 선으로 표시합니다. 손이 작거나 흐리거나 가려졌을 때는 생략할 수 있습니다. 손용 신경망·GPU 연산·학습 코드를 직접 작성했고 손용 외부 사전학습 가중치는 사용하지 않았습니다. 기존 몸 가중치는 사용자의 선택대로 유지했습니다. [초기 손 학습](HAND-VALIDATION.md) · [최신 손 탐색 개선과 검증](HAND-SEARCH-VALIDATION.md)

## 실행

최신 Chrome 또는 Edge에서 웹사이트를 열고 **사진 · 동영상 선택**을 누르거나 파일을 끌어 놓습니다. 동영상은 결과 아래 재생·일시정지·위치 이동·반복 재생을 지원합니다. 원본·뼈대·관절 표시와 선 두께를 바꿀 수 있고, 결과 PNG도 저장합니다.

- **작은 인물도 자세히 찾기**: 화면을 나누어 추가 탐색합니다. 끄면 빠르지만 작은 사람을 더 놓칠 수 있습니다.
- **관절 위치 정밀 보정**: 상체와 하체를 확대해 다시 분석합니다. 기본값은 켜짐이며, 처리 시간이 늘어납니다.
- **몸과 손가락 함께 인식**: 몸의 왼쪽·오른쪽 손목에서 손 영역을 만들고 함께 추적합니다. 끄면 손 분석을 생략합니다. 몸통이 화면에 없을 때도 손 영역을 탐색합니다. 인물을 확인할 수 없는 손은 가상의 몸을 만들지 않고 손만 표시합니다. 몸 손목의 제안 영역은 약 32px부터 검사하지만 작은 손가락은 놓칠 수 있습니다. 낮은 해상도를 확대해도 원래 없던 손가락 정보가 복구되는 것은 아닙니다.
- **인식 민감도 0~100**: 높일수록 더 많은 후보를 찾습니다. 100은 정확도 100%라는 뜻이 아니며, 오검출이 늘어날 수 있습니다. 기본 50은 기존 검출 임계값 0.5와 같습니다.
- **실시간 재생**: 새로 디코딩된 프레임을 분석하고, 주기적인 전체 탐색 사이에는 인물의 이전 위치로 관절을 분석합니다. 추적이 불안정하면 같은 프레임에서 다시 탐색합니다.
- **정밀 재생**: 빠른 동작을 놓치기 쉬운 기기에서는 분석을 기다리며 천천히 재생합니다. 1/30초 간격으로 이동하므로 원본이 60 FPS라면 모든 원본 프레임을 분석하는 방식은 아닙니다. 실시간 재생에는 0.5배·1배·2배 속도 설정도 있습니다.
- 첫 분석에는 약 46 MB의 가중치를 준비합니다. WebGPU를 지원하는 브라우저·기기가 필요합니다.
- 선택한 사진·영상은 브라우저에서 처리하며 서버에 보내지 않습니다. OpenAI API를 호출하지 않습니다.
- 분석한 영상 프레임과 관절 결과를 함께 표시합니다. 프레임을 무한히 쌓지 않으며 30 FPS는 보장하지 않습니다.
- 이미 선이 그려진 스크린샷을 넣으면 그 기존 선은 원본의 일부로 남습니다. 새 인식 결과와 구별하려면 원본 사진·영상을 사용하세요.

로컬 실행:

```powershell
node scripts/serve.cjs
```

이후 `http://127.0.0.1:3000`을 엽니다. Worker·GPU 모델 로딩 때문에 HTML 더블클릭 방식은 지원하지 않습니다. VS Code에서는 폴더를 열고 **Run and Debug → Movira · 웹사이트 → F5**로 배포 사이트를 열 수 있습니다. 로컬 웹 설정은 먼저 서버를 실행해야 합니다.

## 직접 작성한 부분과 활용한 가중치

앱, GPU 신경망 연산 코드, 이미지 전처리, 크기별 탐색, 중복 제거, 관절 복원과 추가 보정 학습 코드는 직접 작성했습니다. 배포 앱에 ONNX Runtime·TensorFlow.js·OpenCV 같은 외부 실행 라이브러리를 포함하지 않습니다.

사용자가 허용한 공개 사전학습 가중치 **YOLOX-Tiny**와 **RTMPose-s Halpe26**을 활용합니다. 이 기본 가중치를 직접 처음부터 학습한 것으로 표현하지 않습니다. 손 관절 신경망과 손 영역 분류·방향 제안 모델은 자체 초기값부터 학습했습니다. 몸 쪽에서 직접 추가 학습한 것은 **크기·비율·분할 화면 경계에 따른 인물 판별 보정층**입니다. 1,400장으로 예제를 만들고, 이 중 1,120장에서 13,280개 사람/배경 예제를 사용해 180회 학습했습니다.

기본 관절 신경망 전체를 다시 학습한 것은 아닙니다. 원본 가중치 출처, 고지, 파일 해시와 실제 학습 범위는 [MODELS.md](MODELS.md)에 있습니다. 수집한 사진·정답의 이용 조건은 직접 작성한 코드와 별개입니다.

## 학습 데이터

바탕화면 **Movira_test_Video**에 데이터와 학습 결과를 보관합니다. 원본 사진과 픽셀 파일은 Git에 올리지 않습니다.

- `detection-train/`: 추가 보정 학습용 사진 1,400장과 사람 영역 정답·출처.
- `scale-training/`: 직접 실행한 보정 학습 결과와 기록.
- `independent-val/`: 기본 가중치와 추가 보정의 학습 자료와 분리한 새 검증 사진.
- `images/`, `movira-dataset.json`: 이전 관절 정답 편집용 자료. 현재도 편집·추가 보정 학습에 사용할 수 있습니다.

추가 학습 재현:

```powershell
pwsh -File scripts/prepare-models.ps1
pwsh -File scripts/collect-detection.ps1 -PeopleImages 1200 -BackgroundImages 200
node scripts/prepare-calibration.cjs
node scripts/serve.cjs
```

`http://127.0.0.1:3000/.calibrate.html`에서 **학습 시작 → 학습 결과 저장**을 실행합니다. 저장된 결과는 다음 명령으로 적용합니다.

```powershell
node scripts/install-calibration.cjs "저장한 movira-calibration-training.json의 전체 경로"
```

앱의 **학습 데이터 · 보정 모델**에서도 사진을 학습 프레임으로 추가하고 사람 영역과 관절 정답을 편집할 수 있습니다. 보정 학습은 사람 영역을 사용하며 기본 관절 가중치를 변경하지 않습니다. 보정 모델을 JSON으로 저장·불러오기 할 수 있습니다.

## 검증

```powershell
node --test
```

좌표 복원·색 순서·화면 분할·중복 제거·관절 매핑·실제 보정 학습을 검사합니다. 별도로 GPU 연산과 기준 실행 결과의 수치 일치, 실제 사진·영상 재생, 해상도를 바꾼 인식도 확인했습니다. 자세한 측정 조건과 한계는 [SCALE-VALIDATION.md](SCALE-VALIDATION.md)에 기록합니다.

기존 `TRAINING-REPORT.json`, `VALIDATION.md`, `research/prototype/`는 이전 작은 자체 CNN 실험 기록이며 현재 앱의 인식 방식이 아닙니다. 새 학습 기록은 `SCALE-TRAINING-REPORT.json`입니다. COCO train2017에서 나눈 보정층 시험과 COCO val2017의 별도 시험을 구분합니다.

## 현재 소스

- `web/gpu-graph.js`: 직접 작성한 WebGPU 연산과 그래프 실행.
- `web/vision-core.js`, `web/vision-runtime.js`: 이미지·영상의 크기별 탐색과 사람별 관절 복원.
- `web/motion.js`: 인물별 시간 추적, 속도 적응 관절 보정, 불확실한 관절의 비정상 이동 검사와 민감도 변환.
- `web/hand-net.js`, `web/hand-training.js`: 직접 작성한 손 신경망, 역전파, 학습·검증.
- `web/hands.js`: 사람별 양손 영역, 손목 연결·방향·시간 보정과 21개 손 표시점.
- `web/inference-worker.js`: 화면을 막지 않는 분석·학습 처리.
- `web/calibration.js`, `web/calibration-trainer.js`: 직접 작성한 보정층과 지도 학습.
- `web/app.js`, `web/index.html`, `web/style.css`: 파일 선택·영상 재생·편집 화면.
- `web/models/`: 허용된 공개 가중치를 변환한 데이터와 원배포 고지.

가림 추정은 이번 개선의 우선 목표에서 제외했습니다. 작거나 흐린 인물, 빠른 동작, 촬영 조건에 따라 누락·오검출이 발생할 수 있습니다. 2D 선 표시만으로 캐릭터 리타게팅이나 동일한 3D 움직임이 완성되지는 않습니다.

이번 빠른 영상 개선은 관절 움직임 원리를 참고해 직접 작성한 시간 추적·보정 코드입니다. 관절 신경망을 새로 학습한 작업은 아니며 공개 기본 가중치와 기존에 추가 학습한 인물 판별 보정층은 그대로 사용합니다. [동작 원리와 검사](MOTION-VALIDATION.md)

## 배포

main에 커밋·push한 뒤 `pwsh -File scripts/publish.ps1 -Action Deploy`를 실행합니다. web 폴더만 movira-site 브랜치로 보내 GitHub Pages에 게시하며 `-Action Status`로 배포 결과를 확인합니다. 강제 push나 과거 Git 이력 삭제는 하지 않습니다.
