# Movira · 자체 학습 실험 버전

[웹사이트 열기](https://yumin0117.github.io/Movira/) · [소스 저장소](https://github.com/yumin0117/Movira)

이 버전의 앱과 학습 알고리즘은 외부 구현 코드를 가져오지 않고 새로 작성했습니다. OpenAI API, YOLO, MediaPipe, RTMPose, ONNX Runtime, OpenCV, 외부 JavaScript/CSS 패키지와 외부 폰트를 사용하지 않습니다. 미리 학습된 가중치를 가져오지 않습니다. 직접 작성한 합성곱 신경망(CNN), 역전파, 학습 코드로 무작위 초기값부터 학습합니다.

**현재는 실험용 학습 기반입니다. 기존 공개 모델의 자동 관절 인식 성능을 재현한 완성품이 아닙니다.** 직접 작성한 작은 신경망을 무작위 가중치에서 학습합니다. 관절 정답을 입력한 사진, 데이터와 별도 검증, 더 큰 자체 모델 개발이 필요합니다. 영상에서는 처리할 수 있는 간격으로 분석하며 실시간 30 FPS나 모든 사람의 정확한 인식을 보장하지 않습니다.

## 실행

`web/index.html`을 브라우저에서 열면 화면을 사용할 수 있습니다. 파일로 직접 열었을 때는 `자체 모델 JSON 열기`에서 `web/own-model.json`을 선택하세요. 웹사이트에서는 같은 폴더의 자체 학습 모델을 자동으로 엽니다. Chrome 또는 Edge를 사용하세요.

VS Code에서 이 폴더를 열고 **Run and Debug → Movira · 웹사이트 → F5**를 누릅니다. 개발용 로컬 미리보기는 `node scripts/serve.cjs` 후 `http://127.0.0.1:3000`입니다. Node·Git·VS Code는 개발 도구이며 웹 앱에 포함되는 외부 라이브러리는 없습니다. 실행 플랫폼인 브라우저·운영체제는 필요합니다.

1. 사진·동영상을 선택합니다. 동영상은 재생/일시정지·위치 이동·반복 재생을 지원합니다.
2. 자체 학습 모델이 있으면 슬라이딩 영역별 사람 여부와 관절 좌표를 추정합니다. 여러 사람의 후보를 처리하고 겹치는 후보를 제거합니다.
3. **현재 프레임을 학습 사진으로 추가**를 누르면 관절 정답을 작성할 수 있습니다.
4. 사람의 전체 영역을 드래그하고, 관절 이름 순서대로 정확한 위치를 클릭합니다. 점을 드래그해 수정할 수 있습니다. 다른 사람은 **+ 사람 영역 지정**으로 추가합니다.
5. 안 보이는 관절은 **이 관절은 보이지 않음**을 선택합니다. 작성하지 않은 관절을 보이지 않는 관절로 간주하지 않습니다.
6. 학습 데이터를 JSON으로 저장하고, 여러 사진을 준비한 뒤 **새 모델 학습**을 누릅니다. 앞 80% 사진으로 학습하고 뒤 20% 사진으로 검증합니다. 같은 사진의 인물이 두 쪽으로 섞이지 않게 분리합니다.
7. **학습한 모델 저장**으로 보관합니다. 학습 사진·모델·결과는 서버에 전송하지 않습니다. 새로고침 전에 직접 저장하세요.

머리 연결은 목–얼굴 하나입니다. 발목·뒤꿈치·발끝을 별도 정답으로 지원합니다. 해당 관절을 학습한 표본이 부족하면 발을 임의로 생성하지 않습니다. 검출 기준 슬라이더는 사람 후보의 점수를 거르는 설정이며 좌표를 더 정확하게 바꾸지 않습니다.

가림을 사람 존재 여부와 별도로 학습합니다. COCO에서 위치가 주석된 가려진 관절은 낮은 가중치로 좌표 학습에 포함하고, 위치를 모르는 관절은 제외합니다. 사람 영역 일부를 가리는 예제도 직접 생성해 학습합니다. 가려졌다고 예측된 관절은 점선과 속이 빈 점으로 표시하며 **가려진 관절 추정 표시**로 숨길 수 있습니다. 이는 보이지 않는 위치를 정확히 관측했다는 의미가 아닙니다. 전체 인물이 가려진 경우나 학습 범위 밖 장면의 인식은 해결되지 않았습니다.

## 수집 데이터와 재현

데이터 기본 위치는 바탕화면의 **Movira_test_Video** 폴더입니다. 이미지는 코드 저장소에 올리지 않습니다. 공개 데이터의 이미지·정답 좌표는 학습 자료이고, 외부 소프트웨어 코드나 사전학습 모델이 아닙니다. 사진·정답 자체에는 출처와 이용 조건이 있습니다. 새로 작성한 코드라고 해서 수집한 사진까지 직접 소유하는 것은 아닙니다.

수집 스크립트는 원본 COCO 2017 메타데이터에서 이미지 라이선스 id 4(CC BY 2.0), 큰 인물과 충분한 관절 주석이 있는 사진을 선택합니다. 이번 수집은 조건에 해당한 **257장·790명**입니다. `sources.json`에 원본 URL, 라이선스, SHA-256과 변환 내용을 저장합니다. COCO 정답은 CC BY 4.0입니다. 이미지별 출처 확인과 표시는 출시 시 별도로 유지해야 합니다. 상세 내용은 [DATA.md](DATA.md)를 확인하세요.

```powershell
pwsh -File scripts/collect-data.ps1
node scripts/enrich-data.cjs "C:\Users\사용자\Desktop\Movira_test_Video"
node scripts/train.cjs "C:\Users\사용자\Desktop\Movira_test_Video" 100
node scripts/calibrate.cjs "C:\Users\사용자\Desktop\Movira_test_Video"
node scripts/evaluate-occlusion.cjs "C:\Users\사용자\Desktop\Movira_test_Video"
node --test tests/engine.test.cjs
```

수집 스크립트에는 PowerShell 7의 `ConvertFrom-Json -AsHashtable`과 Windows 기본 이미지 기능이 필요합니다. 학습 CLI는 Node 기본 기능과 직접 작성한 `web/engine.js`만 사용합니다. 브라우저에서도 데이터 JSON을 열어 학습할 수 있습니다.

실제 학습 기록은 `TRAINING-REPORT.json`에 저장합니다. 이번 CLI 학습은 처음 192장을 학습, 다음 48장을 검증, 추가 수집한 마지막 17장을 시험에 사용합니다. 과거 실험에서 본 사진을 새 독립 시험에 섞지 않도록 마지막 사진을 추가 수집했습니다. 관절 오차는 **정답 사람 영역을 미리 제공한 경우의 좌표 오차**입니다. 사진 전체의 검출 시험은 별도 precision/recall로 기록합니다. 검증으로 학습 회차를 선택하고 시험 사진은 학습·회차 선택에 사용하지 않습니다. 합성 가림 시험은 원본 사람 영역의 약 9%를 가린 스트레스 시험이며 실제 가림 전반에 대한 보장이 아닙니다. 브라우저 학습은 80/20 분리이므로 화면 검증을 독립적인 최종 시험 결과로 취급하지 않습니다. 작은 신경망은 보지 못한 자세·옷·가림에서 크게 실패할 수 있습니다.

## 구조

- `web/engine.js`: 직접 작성한 명암 특징 추출, 합성곱 신경망, 역전파, 모멘텀 학습, 모델 직렬화, 사람 영역 회귀, 다중 영역 검출, 가림 증강.
- `web/app.js`: 파일 표시, 재생, 관절 편집, 데이터 입출력, 학습·검증 화면.
- `scripts/collect-data.ps1`: 사진과 정답 수집·형식 변환. 외부 코드·가중치는 내려받지 않습니다.
- `scripts/train.cjs`: 자체 모델의 CPU 학습·검증 및 결과 저장.
- `ANATOMY.md`: 관절의 의미, 영상 투영과 실제 회전의 차이.

다음 개발 단계는 더 많은 자세·동작·가림 데이터와 발의 정답, 자체 모델의 공간 해상도와 인식 정확도 향상, 별도 시험 세트의 확대, 그리고 3D 회전 추정과 캐릭터 리타게팅입니다. 현재 2D 점 연결만으로 캐릭터의 동일한 3D 움직임이 완성되는 것은 아닙니다.

## 배포

소스를 커밋하고 main에 push한 뒤 `pwsh -File scripts/publish.ps1 -Action Deploy`를 실행하면 `web/`만 `movira-site` 브랜치로 보내 GitHub Pages에 게시합니다. 기존 외부 패키지를 설치하는 빌드 과정은 없습니다. 배포 상태는 `-Action Status`로 확인합니다. 자동 강제 push나 Git 이력 삭제를 하지 않습니다.

과거 Git 커밋에는 이전 외부 모델 기반 구현이 남아 있습니다. 현재 배포에는 포함하지 않습니다. 과거 코드의 라이선스를 소급해서 바꾼 것은 아닙니다.
